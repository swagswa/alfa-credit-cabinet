# 7. Интерфейс на @alfalab/core-components

Дата: 2026-10-20

## Статус

Принято

## Контекст

Кабинет предпринимателя и кабинет сотрудника банка должны выглядеть как продукт Альфы и быть понятны пользователю без банковской экспертизы. Своя дизайн-система за неделю не делается.

## Решение

Фронт: React + TypeScript + Vite, компоненты из `@alfalab/core-components` (монопакет, одна версия на всё). У компонентов, тем и иконок лицензия MIT.

- Тема `corp`, подключается одним импортом из `@alfalab/core-components-themes`.
- Отступы и сетка через `Gap`, `Space`, `Grid` из библиотеки, а не своим CSS.
- Фирменные шрифты Альфы (Styrene UI, Alfa Interface Sans) коммерческие и в npm-пакеты не входят. В репо их не кладём и с CDN банка не грузим. Используем Inter (SIL Open Font License), файлы шрифта лежат в репо.
- Логотип Альфы только в контексте прототипа для хакатона.

## Последствия

- Экраны сразу выглядят в стиле Альфа-Бизнеса, время уходит на сценарий, а не на вёрстку.
- Монопакет тяжёлый в `node_modules` (около 140 МБ), в бандл попадает только импортированное.
- Компоненты адаптивные и переключаются по брейкпоинту: экраны проверяем на ширине ноутбука, а не только на своём мониторе.
- Inter, core-components и иконки внесены в THIRD_PARTY_NOTICES.
