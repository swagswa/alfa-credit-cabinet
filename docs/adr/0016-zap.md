# 16. Логи на zap

Дата: 2026-10-21

## Статус

Принято

## Контекст

В стеке логгер оставался открытым вопросом: zap напрямую или API slog с zap внутри (`zapslog`). Вариант со slog даёт стандартный интерфейс, но добавляет прослойку и пакет `zap/exp` без гарантий совместимости. Команда работала с zap, а его типизированные поля без аллокаций ничем не хуже.

## Решение

- `go.uber.org/zap` v1.28.0 (MIT), продовый конфиг, JSON в stdout.
- `*zap.Logger` создаётся в `main` и передаётся конструкторам аргументом. Без глобального логгера и `zap.ReplaceGlobals`.
- Запросы логирует echo middleware `RequestLoggerWithConfig` с выводом в zap. Ошибку логирует одна граница (HTTP-обработчик ошибок или activity), слои ниже её только возвращают.
- Temporal SDK получает тот же логгер через адаптер к его интерфейсу `log.Logger`.
- ПДн (паспорт, телефон, ФИО) в поля логов не пишем, ИНН компании можно.

## Последствия

- Один формат логов у api, worker и mocks.
- Адаптер под Temporal пишется руками, это пара десятков строк.
