# 10. Доступ к БД: pgx и SQL руками, миграции golang-migrate

Дата: 2026-10-20

## Статус

Принято

## Контекст

Первый вариант стека брал sqlc (Go-код из SQL-файлов) и goose для миграций. При разборе команда решила, что генерация запросов окупается на большой схеме, а у нас десяток таблиц и запросы с `FOR UPDATE`, CTE и `pg_notify`, которые хочется видеть и править прямо рядом с кодом. Генератор добавляет шаг в `go generate`, проверку в CI и порог входа. pgx и golang-migrate команда знает по рабочим проектам.

## Решение

- Драйвер pgx v5 (`pgxpool`), SQL пишем руками в Go. Генератора запросов и ORM нет.
- Запросы лежат рядом с доменным кодом, который их использует: `internal/credit/store.go`, небольшая структура с `*pgxpool.Pool` и методами. Слоя repository и интерфейсов с одной реализацией нет, интерфейс объявляет потребитель, если нужна подмена.
- Строки в структуры через `pgx.CollectRows`, `pgx.CollectExactlyOneRow` и `pgx.RowToStructByName` (теги `db`), без `Scan` по полям.
- Транзакции через `pgx.BeginFunc`, где нужен уровень изоляции, через `pool.BeginTx`. `credit.Transition` принимает `pgx.Tx`.
- Владение заявкой проверяется в самом запросе (`WHERE id = $1 AND company_id = $2`), нет строки значит `ErrNotFound`.
- Миграции golang-migrate v4 (MIT): файлы `migrations/NNNNNN_name.up.sql` и `.down.sql`, встроены через `embed`, источник `source/iofs`, драйвер `database/pgx/v5`. Применяются библиотекой при старте `api`, драйвер берёт advisory lock, поэтому одновременный старт реплик безопасен. Применённую миграцию не правим, пишем следующую.
- Ограничения (CHECK, UNIQUE, FK) живут в схеме, а не только в коде.

## Последствия

- SQL виден целиком в одном месте и правится без перегенерации. На один генератор меньше в `go generate` и CI.
- Маппинг строк не проверяется компилятором: опечатка в имени колонки или несовпадение типа всплывёт при выполнении. Смягчаем `RowToStructByName` (несовпадение колонок и полей сразу даёт ошибку, а не тихий ноль) и интеграционным тестом на testcontainers-go для каждого метода store.
- Сгенерированного кода в репо меньше: `.gitattributes` помечает только `api.gen.go` и `schema.d.ts`.
